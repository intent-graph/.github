**Make intent, not code, the source of truth.** IntentGraph describes software as one graph of
*intent* (what each part is for, what constrains it, what is still unknown) written at mixed
levels of detail. Code, documentation and specs are projections of that graph, so humans and AI
agents can work on one part of a system without holding all of it in mind.

| Repository | What it holds | License |
|---|---|---|
| [**intent_graph**](https://github.com/intent-graph/intent_graph) | The model and its formalism, the Python library, the `ig-tool` CLI, the agent roles, a VS Code viewer | Source-available (PolyForm Shield 1.0.0) |
| [**ai_tooling**](https://github.com/intent-graph/ai_tooling) | Tools and knowledge bases for working with AI coding agents: `codemap`, documentation CLIs, a level-of-detail practice, development guidelines | MIT (code), CC BY 4.0 (knowledge bases) |
